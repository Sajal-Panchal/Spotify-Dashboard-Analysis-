# Spotify-Dashboard-Analysis-
> Spotify Music Analytics Dashboard built in Power BI to analyze songs, artists, albums, popularity, duration, rankings, release years, and monthly trends with an interactive Spotify-style UI.

## 📌 Project Overview

This project is an interactive **Spotify Music Analytics Dashboard** created in **Microsoft Power BI**.  
It transforms music data into an easy-to-explore analytical experience using a Spotify-inspired dark theme, navigation buttons, KPI cards, charts, tables, and music-player style visuals.

The dashboard focuses on understanding:

- Song and artist performance
- Music popularity
- Album and compilation patterns
- Explicit vs non-explicit content
- Songs by year and month
- Artist-wise song counts
- Top songs by popularity/records
- Song duration and ranking metrics
- Highest and average popularity
- Interactive exploration through multiple dashboard pages

## 🎯 Objectives

1. Analyze the most important metrics in a music dataset.
2. Identify high-performing songs and artists.
3. Compare album types and content categories.
4. Understand popularity trends across time.
5. Build an interactive dashboard suitable for portfolio and business-intelligence presentation.
6. Demonstrate Power BI, DAX, data modeling, visualization, and dashboard-design skills.

## 🚀 How to Use

1. Download or clone the repository.
2. Open the `.pbix` file in Microsoft Power BI Desktop.
3. If required, update the dataset/file path in Power Query.
4. Refresh the data.
5. Use the navigation buttons to explore Home, Overview, Artists, and Songs.
6. Interact with charts, tables, and filters to analyze the music data.
